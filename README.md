# ToDo App v1

HTML・CSS・JavaScriptを使用した、学習用のToDo管理Webアプリケーションです。

## 開発目的

Webアプリケーション開発の一連の工程（要件定義・設計・実装・テスト・公開）を経験し、JavaScriptによるDOM操作やイベント処理などの基礎技術を習得することを目的としています。

## 主な機能

- タスクの追加・削除
- 締め切りの設定・変更
- 締め切り順の並び替え
- 締め切り当日・期限切れのタスクの強調表示
- タスクの完了・未完了の切り替え

## 使用技術

- HTML
- CSS
- JavaScript
