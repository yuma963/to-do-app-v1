# ToDo App v1 要件定義書

**プロジェクト名：** ToDo App v1  
**バージョン：** 1.0  
**開発形態：** 個人開発・学習用  
**使用技術：** HTML / CSS / JavaScript

## 1. プロジェクト概要

### 1.1 開発目的
Webアプリケーション開発の基本的な流れを理解し、HTML・CSS・JavaScriptを使用したToDo管理アプリを開発する。

要件定義、設計、実装、テスト、公開までの一連の工程を経験するとともに、DOM操作、イベント処理、配列、関数などの基礎知識を身につけることを目的とする。

### 1.2 アプリケーション概要
ユーザーがタスクを登録し、締め切りや完了状況を管理できるWebアプリケーションを開発する。

締め切り順の並び替えや、期限が迫ったタスクの視覚的な強調によって、タスク管理をしやすくする。

## 2. 機能要件

### F-01 タスクの追加
- ユーザーはタスク名を入力できる。
- 追加ボタンを押すと、入力したタスクが一覧に表示される。
- タスク名が空欄の場合は追加できない。
- 締め切りを設定しなくてもタスクを追加できる。

### F-02 締め切りの設定・変更
- タスクごとに締め切りの日付を設定できる。
- 締め切りはタスクの追加時に設定できる。
- 登録後も締め切りを自由に変更できる。
- 締め切りを未設定のまま登録することもできる。

### F-03 締め切り順の並び替え
- 並び替えボタンを設置する。
- ボタンを押すと、締め切りが近い順にタスクを並び替える。
- 締め切りが未設定のタスクは一覧の最後に表示する。
- 並び替えは自動では行わず、ボタンが押されたときに実行する。
- 完了済みのタスクも締め切り順の並び替え対象とする。

### F-04 締め切りによる視覚的強調
- 締め切り当日の未完了タスクは背景を薄い赤色にする。
- 締め切りを過ぎた未完了タスクも薄い赤色で表示する。
- 締め切りが翌日以降のタスクは通常の背景色で表示する。
- 完了済みのタスクは期限による赤色表示の対象外とする。

### F-05 完了状態の切り替え
- 各タスクに完了ボタンを設置する。
- 完了ボタンを押すとタスクが完了状態になる。
- 完了したタスク名には取り消し線を表示する。
- 完了済みのタスクを未完了状態に戻せる。
- 完了状態を変更しても、タスクの表示位置は変わらない。

### F-06 タスクの削除
- 各タスクに削除ボタンを設置する。
- 削除ボタンを押すと、対象のタスクが一覧から削除される。
- 他のタスクには影響を与えない。

## 3. 画面要件

アプリケーションは基本的に1画面で構成する。

画面には以下の要素を配置する。

1. アプリケーションのタイトル
2. タスク名の入力欄
3. 締め切りの日付入力欄
4. タスク追加ボタン
5. 締め切り順の並び替えボタン
6. 登録済みタスクの一覧
7. 各タスクの完了・削除ボタン
8. 各タスクの締め切り表示・変更機能

具体的な配置、配色、サイズなどは基本設計工程で決定する。

## 4. データ要件

各タスクについて以下の情報を管理する。

| 項目 | 内容 |
|---|---|
| ID | タスクを一意に識別する値 |
| タスク名 | ユーザーが入力した文字列 |
| 締め切り | 設定された日付、または未設定 |
| 完了状態 | 完了・未完了を示す値 |

## 5. 非機能要件

- PCのWebブラウザで操作できること。
- 基本的な操作が直感的に行えること。
- タスクの追加・削除・変更が画面に正しく反映されること。
- HTML・CSS・JavaScriptを使用し、Reactなどのフレームワークは使用しないこと。
- ソースコードをGit・GitHubでバージョン管理すること。

## 6. 開発対象外の機能

v1では以下の機能を実装しない。

- ユーザー登録・ログイン
- データベースとの連携
- AIによるタスク管理
- Googleカレンダーとの連携
- 通知・リマインダー
- タスクのカテゴリ分け

これらは必要に応じて将来のバージョンで検討する。

## 7. 完了条件

以下の条件をすべて満たした場合、v1の開発を完了とする。

- タスクの追加・削除が正常に動作する。
- 締め切りの設定・変更ができる。
- 並び替えボタンで締め切り順に表示できる。
- 当日および期限切れの未完了タスクが赤色で表示される。
- 完了・未完了を切り替えられる。
- 完了状態が視覚的に確認できる。
- 空欄のタスクが登録されない。
- 締め切り未設定のタスクも登録できる。
- 各機能の動作確認が完了している。
